# Tech Stack - Hytra-Which

## Core
- **Language**: Lua
- **Platform**: Neovim (>= 0.9.0 recommended)

## Dependencies
- **folke/which-key.nvim**: Required for the `loop` mode and UI.
- **nvim-treesitter/nvim-treesitter**: For syntax-aware navigation.
- **nvim-treesitter/nvim-treesitter-textobjects**: Specifically for `move` and `select` functionality.

## Development Tools
- **Conductor**: Project management and tracking.
- **Git Flow**: Version control workflow.
- **StyLua**: (Optional) For code formatting.
